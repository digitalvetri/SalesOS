## Definitions used (§2 verbatim)

| Metric | Formula implemented |
|---|---|
| **Achieved** | Σ `Order.total` where `tenantId`, `salespersonId`, `orderDate ∈ month (IST)`, `simpleStatus ≠ CANCELLED` |
| **Achieved %** | `achievedPct(achieved, target)` from `src/server/domain/v1_1/achieved.ts` — rounded whole %, null when target is 0 |
| **Target** | `SalesTarget[tenantId,userId,monthStart]` → fallback `TenantSettings.defaultMonthlyTarget` → 0 ("No target") |
| **Orders / Completed / Pending (this month)** | Counts filtered on `orderDate ∈ month`, grouped by `simpleStatus` |
| **Payment received** | `Σ Payment.amount` where `paidOn ∈ month`, `status ≠ REJECTED`, order non-cancelled, order belongs to this salesperson |
| **Balance to collect** | `Σ balanceDue` where `salespersonId = me`, `balanceDue > 0`, `simpleStatus ≠ CANCELLED` |
| **Last 6 months** | `to_char(orderDate AT TIME ZONE 'Asia/Kolkata', 'YYYY-MM')` SUM(total) per month, non-cancelled |
