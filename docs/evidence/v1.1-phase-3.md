## Spec gate — "50 parallel creates emit 50 unique sequential S.Nos"

```
$ pnpm exec vitest run tests/integration/order-v2-concurrent.test.ts

 ✓ createOrderV2 — concurrent S.No allocation
    ✓ 50 parallel creates emit 50 unique, sequential S.Nos  3.0s

 Test Files  1 passed (1)
      Tests  1 passed (1)
   Duration  3.23s
```

The retry wrapper (`runWithSerializableRetry` — up to 8 attempts, jittered
exponential backoff) handles P2034 serialization failures AND P2002 unique
constraint races on the global order `number`. In the 50-parallel test, every
S.No landed in 1..50 with no gaps.
