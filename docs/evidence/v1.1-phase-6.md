## Security

- All new Server Actions assertCan server-side:
  - `setTargetAction` → `targets.set` (OWNER/ADMIN only, SALES denied)
  - `setDefaultTargetAction` → `settings.manage` (OWNER/ADMIN only)
  - `changeMyPasswordAction` → `settings.manage`, operates ONLY on the caller's own `authUserId`
- Passwords are stored hashed in Supabase; no plaintext ever leaves the server-role client.
- Export endpoint role-checks (OWNER/ADMIN/ACCOUNTS); SALES gets 403.
